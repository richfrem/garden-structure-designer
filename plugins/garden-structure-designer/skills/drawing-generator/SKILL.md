---
name: drawing-generator
description: Generates architectural SVG drawings and updates the composite dependency manifest.
allowed-tools: Read, Write, Bash
metadata:
  garden_structure_designer:
    consumes:
      - context/staging/structural-model.json
      - context/staging/geometry-calculations.json
    produces:
      - outputs/drawing-plan-view.svg
      - outputs/drawing-elevation-view.svg
    validators:
      - plugins/garden-structure-designer/scripts/svg_validator.py
    repair_axes:
      - svg_xml_invalid
      - svg_topology_mismatch
      - svg_coordinate_drift
---

## Expected Inputs
`context/staging/structural-model.json` generated by `structural-engine`.
`context/staging/geometry-calculations.json` generated by `geometry_engine.py`.
`context/staging/joinery-model.json`
`context/staging/bracing-model.json`

## Core Responsibilities
1. Read inputs.
2. Run `geometry_engine.py` (if `geometry-calculations.json` missing or out of date).
3. Run `render_drawings.py` to deterministically generate SVG files without hallucination.
4. Run `svg_validator.py` on each output.
5. Update the composite dependency manifest.

## Semantic Topology
All generated SVGs MUST embed `data-role` and `data-id` attributes on structural elements:
`<rect data-role="post" data-id="P1" x="..." y="..." fill="#c8a96e" />`

## Execution
```bash
python3 scripts/render_drawings.py context/staging/structural-model.json
```
