---
name: joinery-designer
description: Determines joinery type per connection based on structural model bounds and user preferences. Explains load transfer behavior and outputs joinery maps.
allowed-tools: Read, Write
---

## Expected Inputs
`context/staging/structural-model.json` generated by `structural-engine`.
User preference for joinery (mechanical fasteners vs traditional timber framing).

## Core Responsibilities
1. Evaluate all post-to-beam, beam-to-rafter connections.
2. If traditional timber framing chosen: assign half-laps, mortise and tenons, or housing depths.
3. If mechanical chosen: assign specific bolt patterns and Simpson Strong-Tie brackets.
4. Output specifics to `context/staging/joinery-model.json`.
