# Assembly Guide: Saanich Hexagon Gazebo (10ft Final)

**Structure:** 10' Diagonal Hexagon Pavilion  
**Target:** Professional Carpenters / Skilled DIY  
**Source Blueprints:** [Saanich-Hexagon-Gazebo-Construction-Set.pdf](../output/pdf/Saanich-Hexagon-Gazebo-Construction-Set.pdf)

---

## Phase 1: Site Layout & Footings
1.  **Establish Center Point:** Drive a central stake. 
2.  **Mark the Hexagon:** Use a 5-foot string (the radius). Mark exactly 6 points every 5 feet around the circumference. 
    *   *Check:* The distance between any two adjacent points MUST be exactly 5'-0".
3.  **Excavation:** Dig six 18" Dia caissons at the marked points.
4.  **Concreting:** Pour concrete. Wet-set 1/2" J-bolts using a template to ensure exact 5'-0" C-C spacing. 
5.  **Cure:** Allow 48-72 hours before loading.

## Phase 2: Post & Beam Ring
1.  **Post Prep:** Cut six 6x6 posts to 8'-4" (100"). Notch tops if using a "housed" beam seat, or prep for knife plates.
2.  **Standoff Bases:** Install ABA66Z bases onto J-bolts.
3.  **Erect Posts:** Set posts, plumb in both directions, and brace temporarily.
4.  **Beam Installation:** Install the 6x6 ring beams. 
    *   *Pro Tip:* Build the hexagon ring segments on the ground if possible, or fly them in one by one.
    *   *Joinery:* Use 5/16" x 8" RSS screws through the top of the beam into the post.

## Phase 3: The "Star" Assembly (Hub & Rafters)
1.  **Hub Prep:** Secure the 8x8 Hex Hub.
2.  **Ground Rafter Assembly:** Pre-pair 3 rafters to the hub on the ground to create a "tripod" for stability.
3.  **The Big Lift:** Hoist the Hub/Tripod assembly. Rest the rafter tails on the ring beams.
4.  **Fill In:** Install the remaining 3 rafters.
5.  **Fastening:** 
    *   Hub end: 2x SDS 6" Lags per rafter.
    *   Beam end: H1 Hurricane ties or decorative structural plates.

## Phase 4: Roof Decking
1.  **Start at Eaves:** Install the first row of 1x6 T&G Cedar. Ensure it is perfectly level.
2.  **Work Upward:** Overlap/interlock the T&G rows. 
3.  **Trimming:** Trim the hip intersections flush to the rafter center-line.
4.  **Shingling:** Apply felt/underlayment, then cedar shingles at a 5" exposure.
5.  **Ridge Caps:** Install 6 rows of ridge caps on the hips.

---

## 🛠 Critical Safety & QC Check
*   **Plumb Check:** Re-verify post plumb *after* the ring beam is tight but *before* the roof is decked.
*   **Pitch Check:** Verify the 4:12 slope (approx 18.4°) on the first rafter pair before committing the full set.
*   **Clearance:** Confirm 7'-10" headroom from the finished patio/deck surface to the underside of the beam.
